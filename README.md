# FocusFlow – Student Productivity & Focus Assistant

## Project
FocusFlow is a front-end web application that helps students manage tasks, goals, focus sessions, schedules, productivity progress, and achievements.

## Technologies
- HTML
- CSS
- JavaScript
- Browser Local Storage (built-in browser feature; no SQL/database required)

## Main Features
- Dashboard
- Task management
- Task search and filtering
- Goals and progress
- 25-minute focus timer
- Daily schedule
- Productivity report
- Achievements
- Dark/light mode
- Responsive design
- Local browser storage

## How to Run
1. Extract the project folder.
2. Open `index.html` in Google Chrome, Microsoft Edge, or another modern browser.
3. No installation or server is required.

## Team Division
1. HTML – page structure and sections
2. CSS – interface and responsive design
3. JavaScript – tasks, goals, timer, progress and interactions
4. Testing & documentation – testing all features and preparing the presentation

## Important
This version intentionally does not use Python, Flask, SQL, or Tkinter. It is a pure HTML/CSS/JavaScript project.
